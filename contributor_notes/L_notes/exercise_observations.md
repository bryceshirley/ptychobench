# 1

Increasing the modulus decreases the intensity of the field propagation amplitude of all methods decreases.

# 2

Increasing the divergence angle increases how spread out the lines are in 2D field propagation amplitude.

# 3

Using Straight Wave Guides, increasing the modulus makes field propagation amplitude more defined and field propagation phase more complicated.

# 4

Using Straight Wave Guides, increasing the period makes the field propagation amplitudes thinner. Increasing core width causes field propagation phase to become more noisy and makes field propagation amplitude thinner and more like a vertical sine wave.
