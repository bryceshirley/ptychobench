# Markdown Cheat Sheet

## Headings and Titles
| Element | Syntax |
| :--- | :--- |
| Main Title | `# Heading 1` |
| Section Heading | `## Heading 2` |
| Subsection Heading | `### Heading 3` |
| Sub-subsection Heading | `#### Heading 4` |

## Text
| Element | Syntax | Result |
| :--- | :--- | :--- |
| **Italic** | `*text*` or `_text_` | *text* |
| **Bold** | `**text**` or `__text__` | **text** |
| **Bold + Italic** | `***text***` | ***text*** |
| **Strikethrough** | `~~text~~` | ~~text~~ |

## Lists
| Type | Syntax | Result |
| :--- | :--- | :--- |
| **Unordered** | `- Item` | • Item<br>&nbsp;&nbsp;&nbsp;&nbsp;• Sub-item |
| **Ordered** | `1. Item 1`<br>`2. Item 2` | 1. Item 1<br>2. Item 2 |
| **Task List** | `- [ ] Todo`<br>`- [x] Done` | ☐ Todo<br>☑ Done |

## Elements & Code
| Element | Syntax |
| :--- | :--- |
| **Link** | `[Text](https://example.com)` |
| **Image** | `![Alt Text](image.jpg)` |
| **Blockquote** | `> Text here` |
| **Inline Code** | `` `code` `` |
| **Code Block** | \`\`\`language <br>code lines<br>\`\`\` |
